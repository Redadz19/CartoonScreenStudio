# Cartoon Screen Studio

مشروع أندرويد أصلي باستخدام Kotlin و Jetpack Compose.

## المتطلبات
- Android Studio حديث (يفضل Ladybug أو أحدث)
- JDK 17
- Android SDK 35
- جهاز Android 8.0 أو أحدث للتجربة

## التشغيل
1. فك ضغط المشروع.
2. افتح مجلد `CartoonScreenStudio` في Android Studio.
3. انتظر Gradle Sync.
4. شغّل التطبيق على هاتف حقيقي أو محاكي يدعم MediaProjection.
5. اضغط «بدء تسجيل الشاشة» ووافق على نافذة النظام.

## ما يعمل في هذه النسخة
- واجهة عربية RTL بتصميم داكن ملون.
- طلب إذن تسجيل الشاشة من النظام.
- تسجيل الشاشة إلى MP4 مع صوت الميكروفون.
- استيراد فيديو من الهاتف عبر منتقي الملفات.
- معاينة كرتونية لإطار مستخرج من الفيديو.
- تصدير الفيديو كاملاً إلى MP4 صامت بتأثير posterize + edge محلي دون إنترنت، حتى 720p و12 إطار/ثانية.
- حفظ صورة المعاينة بصيغة PNG في معرض الصور.

## حدود النسخة الحالية
أصبح تصدير الفيديو كاملاً إلى MP4 متاحاً كتأثير كرتوني تقليدي مبسط، مع أخذ عينات حتى 12 إطار/ثانية وحد أقصى 720p. ملف MP4 الناتج لا يحتوي على الصوت في هذه النسخة. هذا التأثير ليس نموذج ذكاء اصطناعي توليدي ولا ينتج مظهر أنمي/ثلاثي الأبعاد واقعياً؛ تلك خطوة لاحقة تتطلب نموذج تعلم عميق مناسباً. لا يتطلب هذا المشروع أي مفتاح API حالياً.

## ملاحظات التسجيل
- التسجيل يعتمد على MediaProjection وموافقة المستخدم في كل جلسة وفق قيود أندرويد.
- صوت الميكروفون هو المسار الصوتي المضاف في هذه النسخة؛ التقاط الصوت الداخلي يعتمد على إصدار أندرويد والتطبيق المصدر وسياسة النظام.
- الملفات تُحفظ في مجلد التطبيق الخاص: `Android/data/com.example.cartoonscreenstudio/files/Recordings`.
